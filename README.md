This is a Minecraft mod designed for use within the [DiamondFire](https://mcdiamondfire.com/) server's dev mode that allows for various personal minor tweaks. Uploaded to GitHub mostly for version control between computers.

It was mostly written by hand, with AI assistance (e.g. getting the Fabric function to interact with Minecraft in a specific way), although updating to 26.2 (where all Minecraft-based method signitures changed significantly) relied on AI use.
